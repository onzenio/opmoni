# opmoni — frontend

Dashboard Nuxt 4 + Vue 3 + Nuxt UI (`pnpm@12.5.1`). Páginas: `app/pages/` (`index`, `customers`, `inbox`, `settings`).

```bash
corepack enable && pnpm install
pnpm dev        # :3000
pnpm build && pnpm preview
pnpm lint && pnpm typecheck
```

Entradas: `app/app.vue`, `app/pages/`, `app/layouts/`, `server/api/`, `nuxt.config.ts`.
Guia do agente: ver `AGENTS.md` (raiz).
